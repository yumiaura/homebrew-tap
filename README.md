# yumiaura/homebrew-tap

Homebrew casks for [myCat](https://github.com/yumiaura/myCat), a tiny animated desktop pet cat.

```bash
brew install --cask yumiaura/tap/mycat
```

`mycat.app` is not signed by Apple: the first time, right-click it in Applications and choose **Open**.

The cask is updated automatically by the myCat release workflow on every new version.
